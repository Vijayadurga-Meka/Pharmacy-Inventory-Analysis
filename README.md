# Pharmacy Inventory, Stock-Out & Medicine Expiry Analysis

## Project Overview

This project uses Microsoft Power BI to analyze pharmacy inventory, medicine sales, stock availability, and expiry status. The dashboard helps identify out-of-stock medicines, understand sales trends, and monitor inventory levels to support better inventory management and decision-making.

## Objectives

- Monitor total stock received, stock issued, and remaining inventory.
- Analyze total sales revenue and monthly sales trends.
- Identify top-selling medicines.
- Identify medicines with zero remaining stock.
- Analyze inventory distribution across medicine categories.
- Monitor medicine expiry status using a defined historical reference date.

## Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data transformation and cleaning
- **DAX** – Calculated measures and analytical logic
- **Kaggle** – Dataset source

## Dashboard Features

### Key Performance Indicators (KPIs)

- Total Stock In
- Total Stock Out
- Total Remaining Stock
- Total Stock Value
- Total Sales Revenue
- Out-of-Stock Medicines
- Total Medicines

### Visualizations

- Top 10 Medicines by Sales
- Monthly Sales Trend
- Medicine Stock-Out Analysis
- Remaining Stock by Category
- Stock Distribution by Expiry Status
- Expiry Status by Category

### Interactive Filters

The dashboard includes slicers to explore the data by date range, medicine category, and supplier.

## Key Insights

The dashboard helps users explore:

- Which medicines contribute most to sales.
- How sales change over time.
- Which medicines have zero remaining stock.
- How inventory is distributed across medicine categories.
- Which medicines fall into different expiry-status groups.

Actual business findings should be documented after reviewing the final dashboard results.

## Data Model

The project organizes data into related tables, including:

- **Medicine** – Medicine details and categories
- **Inventory** – Stock movements, remaining stock, and expiry information
- **Sales** – Medicine transactions and sales quantities
- **Suppliers** – Supplier details and delivery information
